# Slack 側の準備手順

A-5b の Bot を動かすための、Slack 側の準備。**あなたの Slack アカウントでの操作になる。**

所要時間の目安：20分
照合日：2026-10-16（slack-bolt 1.30.0）。画面の文言は Slack 側の更新で変わることがある。
見当たらない項目があれば、**止めて連絡する。**

---

## 0. 前提

- Slack のアカウントがある
- **業務で使っているワークスペースは使わない。** 自作アプリの導入には管理者の承認が要ることが多く、
  検証で業務の場を汚さないため。テスト用のワークスペースを新しく作る

---

## 1. テスト用のワークスペースを作る（5分）

Slack にログインした状態で、新しいワークスペースを作る（無料プランでよい）。
名前は何でもよい（例：`a5b-test`）。

作ったら、チャンネルを1つ作っておく：`#inquiry-test`（問い合わせを送る場所）。

**確認**：ブラウザかアプリで、そのワークスペースの `#inquiry-test` が開けること。

---

## 2. アプリをマニフェストから作る（3分）

1. https://api.slack.com/apps を開き「**Create New App**」
2. 「**From an app manifest**」を選ぶ
3. ワークスペースに、1 で作ったテスト用のものを選ぶ
4. 入力欄の形式を **YAML** にし、このリポジトリの `projects/a5b-slack-bot/manifest.yaml` の中身を**すべて**貼る
5. 内容の確認画面で「**Create**」

**確認**：アプリの管理画面が開き、左のメニューに「Basic Information」などが並んでいること。

> マニフェストで作る理由：画面で1つずつ権限を選ぶより手順が短く、
> **どの権限を要求しているかがファイルに残る。** 権限を足すときも、ファイルの差分で説明できる。

---

## 3. アプリレベルトークンを作る（3分）

Socket Mode（公開 URL なしで動かす方式）の接続に使うトークン。

1. 左のメニュー「**Basic Information**」→ 下の方の「**App-Level Tokens**」
2. 「**Generate Token and Scopes**」
3. 名前：`socket`（何でもよい）
4. 「Add Scope」で **`connections:write`** を選ぶ
5. 「Generate」→ 表示された **`xapp-` で始まるトークン**を控える

> **チャットに貼らないこと。** 4 で `connections:write` が見当たらなければ止めて連絡する。

---

## 4. ワークスペースにインストールする（2分）

1. 左のメニュー「**Install App**」（または「OAuth & Permissions」）
2. 「**Install to （ワークスペース名）**」→ 権限の確認画面で「**許可する**」
3. 表示された **`xoxb-` で始まる Bot User OAuth Token** を控える

**承認画面で要求されている権限を読む。** 「スラッシュコマンドの追加」と「メッセージの送信」に当たる2つのはず
（マニフェストの `commands` と `chat:write`）。

---

## 5. `.env` に入れる（5分）

```bash
cd /Users/haruto/dev/ax_tutorial/projects/a5b-slack-bot
cp .env.example .env
```

`.env` をエディタで開き、3つの値を `=` の後ろに貼る。

| キー | 値の元 |
|---|---|
| `SLACK_BOT_TOKEN` | 手順4の `xoxb-` で始まるトークン |
| `SLACK_APP_TOKEN` | 手順3の `xapp-` で始まるトークン |
| `GEMINI_API_KEY` | A-1 で使った Gemini の API キー（A-1 の GAS のスクリプトプロパティ `GEMINI_API_KEY` にある） |

> **日本語入力を切ってから編集する。** 全角スペースが混ざると、見た目で区別できないまま壊れる（A-6a で踏んだ）。
> **キー名は書き換えない。** 打ち間違えるとエラーにならず未設定扱いになる（A-6a で踏んだ）。

### 正しく入ったかを確かめる（値は表示されない）

```bash
uv run python src/settings.py
```

次のように出れば正しい。

```
  SLACK_BOT_TOKEN  入力あり（NN文字）・先頭OK
  SLACK_APP_TOKEN  入力あり（NN文字）・先頭OK
  GEMINI_API_KEY   入力あり（NN文字）

問題なし
```

`★` が付いた行があれば、その指摘に従って直す。
（例：先頭が違う → 2つのトークンを取り違えている／空白が含まれている → 全角スペースの混入）

---

## 6. Bot をチャンネルに招待する（3分）

`routing.json` に書いた通知先のチャンネル（`#inq-system`・`#inq-general`・`#inq-ops`）を作り、
それぞれで次を送る。**招待していないチャンネルには通知できない**（`not_in_channel`）。

```
/invite @inquiry-bot
```

**確認**：「inquiry-bot がチャンネルに参加しました」と出ること。
