# A-2：RAG と評価設計

工程書：[docs/process/20-A2-rag.md](../../docs/process/20-A2-rag.md)

## 想定構成

```
a2-rag/
  corpus/       題材文書 50〜100件（意図的に汚す）＋ 生成スクリプト
  eval/         30問の評価セット・採点スクリプト
  systems/
    notebooklm/ 構築ゼロ方式の手順と結果
    dify/       Dify 側の設定エクスポートと結果
    custom/     自作（LlamaIndex等 + Drive連携）
  results/      方式 × 問 × 判定 の比較表
```

**順序厳守：`eval/` を先に作る。** 構築後に評価セットを作ると、
無意識に自分の実装に有利な質問を選ぶため、数値がすべて無意味になる。

Python は `uv` で管理。ベクトルストア・インデックスは再生成可能なので `.gitignore` 済み。
