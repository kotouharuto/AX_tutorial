# コンテキスト設計テンプレート（副業用・汎用）

顧客組織専用の AI 作業環境（Claude Project / Cowork / Skills 等）を設計するための骨格。
**特定組織の内容は含まない。** 各ファイルの「答える問い」に、顧客ごとの答えを書き込んで使う。

A-3 で架空企業向けに1回通した経験から作った。
問いの横に「なぜ聞くか」を付けてある。落とし穴を踏んだ経緯があるものは記録へのリンクを付けた。

## 構成

| ファイル | 役割 | 使う場面 |
|---|---|---|
| [00-intake.md](00-intake.md) | 案件開始時に顧客に聞くこと | 初回打ち合わせ |
| [01-instructions.md](01-instructions.md) | AI への指示書の骨格 | 設計 |
| [02-glossary.md](02-glossary.md) | 用語集と、ナレッジ投入の選別 | 設計・投入 |
| [03-procedure.md](03-procedure.md) | 利用者向け手順書の骨格 | 引き渡し |

## 使い方

1. **00 を顧客と一緒に埋める。** ここで答えが出ない項目は「未決」として残し、誰がいつ決めるかを合意する
2. 01 → 02 → 03 の順に埋める
3. 02 の投入チェックリストを通してからナレッジを投入する
4. 03 を、**その業務を知らない人に読ませて**1件こなせるか試す

## 守ること

- 前の案件で書いた答えを流用しない。問いに対して、その組織の答えを書く
- 「答える問い」に答えられないセクションは、**その組織で決まっていないこと**。空欄のまま「未決」と書く
- テンプレートに無い問いが必要になったら、テンプレート自体に追加する（次の案件のため）
