# 02. 用語集と、ナレッジ投入の選別

## A. 用語集

ナレッジに追加する文書。利用者の表記が揺れても同じものとして扱わせる。

**材料の集め方：** 文書を全文検索して、同じ対象の別表記・略語・旧称を機械的に列挙する。
「何があるか」を人の記憶に頼らない。

| 表 | 決めること |
|---|---|
| 同じものを指す複数の表記 | 正はどれか |
| 同じか別か、判断が要るもの | 同じか別か |
| 部署・窓口・連絡先 | 文書間で食い違っていたら、正を1つ決めるか「文書により異なる」と明記するか |
| 旧称と新称 | 旧版をナレッジから外すか、残して注記するか |
| 役職・権限の語 | 定義（文書に定義がなければここで書く） |
| 誤記 | 原文ママか、正すか |

## B. 投入前チェックリスト

**設計で「外す」と決めた文書が、投入作業で混ざる。** これを防ぐ。
（→ [記録](../../../docs/pitfalls/a3-knowledge-curation-beats-instructions.md)）

```
□ 「外す」リストと、投入するファイル一覧を突き合わせた
□ 同じ文書番号で複数の版が無いことを確認した
□ 利用者全員が閲覧してよい文書だけになっていることを確認した
□ 投入後、ファイル数が設計書の想定と一致することを確認した
□ 用語集（A）を1ファイルとして投入した
```

## C. 更新時のルール

- 追加・更新できるのは誰か
- 更新時に旧版を消すか
- 新しい表記が増えたら用語集を直すか
- 分類が増えたら指示書を直すか
- 追加したことを誰に知らせるか
