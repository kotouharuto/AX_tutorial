# 用語集（社内問い合わせ対応）

利用者の表記が揺れていても、以下の対応に従って同一のものとして扱う。

## 同じものを指す表記
- **WiFi**（別表記: Wi-Fi / WiFi / 無線LAN / 無線）
- **リモートワーク**（別表記: テレワーク / リモートワーク / 在宅勤務）
- **パスワード**（別表記: パスワード / PW）
- **立替精算システム**（別表記: ワークフロー / 立替精算システム / 電子申請システム）

## 語の区別
- 「経費精算」と「立替精算」→ 正は **経費精算**
- 「情シス」と「情報システム部」→ 正は **情報システム部**
- 「情報システム部ヘルプデスク」と「情シス」→ 正は **情報システム部ヘルプデスク**
- 「総務部」と「総務部設備担当」→ 正は **総務部設備担当**

## 窓口と内線
- 情シス（一般）：内線 4400（IT-103 では「AX推進部 兼 情シス統括」が4400）
- 情報システム部ヘルプデスク：内線 4401（端末個別の問題・ロック解除）
- ネットワーク管理課：内線 4455（フロア全体の障害）
- AX推進部 兼 情シス統括：内線 4400（全社的な障害）
- 総務部設備担当：内線 3300（プロジェクタ等）
- 総務部：内線 3300（社用車事故時）

## 役職
- 所属長：課長職以上の直属の上長
- 部門長：部長職以上
- 担当役員：当該部門を管掌する取締役

## 誤記
- 「北side」は「北側」の誤記
