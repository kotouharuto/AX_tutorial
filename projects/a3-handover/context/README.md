# A-3 ステップ②：非エンジニアに渡せる形（架空企業「社内問い合わせ対応」）

A-1（問い合わせ振り分け）と A-2（社内文書検索）を統合し、
Claude Project の設定として「その組織専用の作業環境」に組み直す。

## 構成

| ファイル | Claude Project での置き場所 | 書く人 |
|---|---|---|
| [01-instructions.md](01-instructions.md) | Custom Instructions（プロジェクト指示） | あなた |
| [02-glossary.md](02-glossary.md) | ナレッジに追加する文書 | あなた |
| [03-procedure.md](03-procedure.md) | 利用者に渡す手順書（Project の外） | あなた |
| A-2 の `corpus/out/` 60文書 | ナレッジ | 投入のみ |

## 書く順序

**01 → 02 → 03**。指示書で「何をどう判断するか」を決めてから、用語集と手順書に降ろす。

## 守ること

- **社内で書いた設計ファイルを参照しない。** 白紙から書く（ロードマップの指示）
- 各セクションの「答える問い」に答える形で埋める。問いに答えられないセクションは、
  **その組織で決まっていないこと**なので、空欄のまま「未決」と書く
- A-1・A-2 で踏んだ落とし穴が、どの記述で防がれるかを意識する（各問いに対応を書いてある）

## 完了の判定

03 の手順書を、**この題材を知らない人が読んで、問い合わせ対応を1件こなせるか。**
ステップ⑥「他人に触ってもらう」で実際に試す。
