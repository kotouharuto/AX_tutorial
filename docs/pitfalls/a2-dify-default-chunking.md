# Dify の既定チャンク設定は改行ごとに分割し、見出し・日付・表構造を本文から切り離す

- **ブロック：** A-2
- **日付：** 2026-09-13
- **一般性：** Dify を既定設定で使う全ケース
- **溶かした時間：** 約 1.0 時間（原因特定と30問の採点）

## 事象

同じ60文書・同じ30問・同じモデル（gemini-3.6-flash）・同じ前置きで測ったところ、
**GUI で既定のまま作った Dify が、手で書いた自作RAG に 3.5 点負けた。**

| 方式 | 総合 | 横断 | 表 |
|---|---|---|---|
| 自作（chunk=512、1文書1チャンク） | 28.0/30 | 7/8 | 5/5 |
| **Dify（既定チャンク）** | **24.5/30** | **5/8** | **3.5/5** |

差の 3.5 点は**すべてチャンクの切り方に起因**する。

## 何が起きたか

Dify の既定チャンク設定は**改行ごとに1チャンク**にする。

```
ASSET-402（280字） → 12チャンク
  1|社用車の利用規程         ← タイトル
  2|利用資格                 ← 見出し
  3|入社1年以上かつ運転免許取得から3年以上の社員。
  4|利用前に安全運転講習（年1回）の受講が必須。
  ...
```

これが3種類の失点を生んだ。

### 1. 日付と本文が分離 → 新旧の判断ができない（-1.5）

```
REG-001-2025
  2|制定日：2025年4月1日                          ← 検索されない
  7|経費の精算申請は…翌月5日まで…                 ← 検索される
```

「経費精算の申請期限」という質問は制定日チャンクにマッチしない。
LLM は**日付を一度も見ないまま**「翌月5日と翌月10日の記載が混在しています」と答えた。

既製方式（NotebookLM / Claude Projects）は制定日を見て新しい方を選び、旧版を注記した。
**同じモデルなのに判断が変わったのは、見えている情報が違うから。**

### 2. 表のヘッダと行が分離 → 正解文書が検索から消える（-2.0）

```
TBL-502
  3|5万円未満 5万〜20万円 20万〜100万円 100万円以上    ← ヘッダ（「外注費」がない）
  6|外注費 部門長 部門長 担当役員 取締役会              ← 行（「100万円」がない）
```

「100万円以上の外注費」はどちらにもマッチしない。**TBL-502 が検索結果に1つも入らず**、
LLM は「記載がありません」と答えた。正解は存在するのに、検索の段階で消えている。

Q19 ではさらに悪く、**別文書の類似チャンク**（出張の承認フロー「5万〜20万円：部門長」）を
正解の代わりに掴んで「部門長」と誤答した。

### 3. 見出しチャンクが検索上位を占有（top_k で切れる）

top_k=3 では「本文1つ＋見出し2つ」が返り、4番目の本文（安全運転講習）が切れた。
**見出しは短いので、どんな検索方式でもスコアが高く出やすい。**

経済的モード（キーワード検索）ではこれが極端に出て、
**5件返しても全部が見出しかタイトル**で、本文が1つも入らなかった。

## 対処

**既定のまま使わない。** チャンク設定を「カスタム」にして、最低限：

- 区切り文字を `\n\n`（空行）または見出し記号にし、**見出しと直下の本文を同じチャンクに入れる**
- 最大チャンク長を数百字以上にする
- 表を含む文書は、**表全体が1チャンクに収まる長さ**にする

または、**出典名（ファイル名）をコンテキストに含める。** 自作RAG では
`--- 出典: REG-001-2025_経費精算規程.md ---` を付けていたため、
制定日チャンクが無くてもファイル名の年号で新旧を判断できた。
Dify の `{{#context#}}` は本文だけを埋め込むので、この手がかりが無い。

## 他人の環境に納品するときの含意

- **「GUI で既定のまま作れる」は、既定値が題材に合っていることが前提。**
  Markdown の見出し構造や表を含む文書では、既定チャンクは構造を壊す。
- 顧客の文書を投入する前に、**数件のチャンク結果を目で見る。**
  Dify のドキュメント詳細画面でセグメントは確認できる。
  「利用資格」だけのチャンクが並んでいたら、その設定では使えない。
- 「引用」が正しい文書名を示していても、**渡っている中身は見出しだけ**という状況が起きる。
  引用表示を検索の成功と解釈しない。
