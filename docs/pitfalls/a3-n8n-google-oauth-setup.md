# n8n から Google を使うための OAuth 設定（GAS では不要だった6手順と、詰まり4箇所）

- **ブロック：** A-3
- **日付：** 2026-09-13〜14
- **一般性：** n8n に限らず、Google の外にあるツールから Workspace を操作する全ケース
- **溶かした時間：** 約 2.0 時間（GAS 版は承認1回・数分）

## GAS と n8n の手順数

| | GAS | n8n |
|---|---|---|
| 必要な作業 | `clasp push` → 承認画面で許可 | GCP プロジェクト作成 → API 有効化 ×3 → OAuth 同意画面 → テストユーザー追加 → クライアント ID 作成 → n8n にクレデンシャル登録 ×3 |
| 承認回数 | 1回 | 3回（Sheets / Sheets Trigger / Gmail） |
| 要求スコープ | `spreadsheets.currentonly`（このシートのみ）`gmail.send` | `spreadsheets`（**全スプレッドシート**）`drive.file` `drive.metadata` + Gmail 系 |

**同じ「シートを1行読んでメールを送る」処理で、権限が「1ファイル」から「アカウント内の全ファイル」に広がる。**
GAS は Google の中にいるので「このファイルだけ」と言える。n8n は外にいるので、
Google から見れば「どのファイルを触るか事前に分からない第三者」——だから広い権限を求めざるを得ない。

## 詰まり1：テストユーザー未登録で 403 access_denied

OAuth 同意画面が「テスト」モードのままだと、登録したテストユーザーしかサインインできない。
A-1 で見た「確認されていません」は**警告（進める）**だったが、これは**ブロック（進めない）**。

**本番公開しようとしたら、ホームページ URL とプライバシーポリシー URL が必須**だった。
Google の要件が変わっている。個人検証には過剰なので、テストユーザー追加で回避した。

→ **n8n で Google 連携を本番運用するなら、自分のドメインとプライバシーポリシーページが要る。**
GAS では一切不要。これは技術ではなく事業側の準備で、Phase B の論点になる。

## 詰まり2：invalid_client（Secret の不一致）2回

1回目：Secret のコピーミス。2回目：GCP で Secret を再発行したら古い方が無効化され、
n8n に古い方が残っていた。

エラーは「Client authentication failed」としか言わず、ID と Secret のどちらが悪いかは示さない。
承認画面まで進んだなら ID は正しい（URL に含まれて通っている）ので、Secret を疑う。

## 詰まり3：接続済みのクレデンシャルを開いて触ったら、接続が壊れた

翌日、既に connected だった Sheets のクレデンシャルが未接続に戻っていた。
**Client ID / Secret 欄を触って保存すると、n8n は既存トークンを無効として扱う。**
ノードでクレデンシャルを「選ぶだけ」なら画面を開く必要はなかった。

GUI は「触っただけで壊れる」ことを警告しない。

## 詰まり4：Sheets Trigger は別種のクレデンシャル

読み書きノード用の「Google Sheets OAuth2 API」は、トリガーノードには使えない。
「Google Sheets **Trigger** OAuth2 API」を別に作る必要がある。

同じ Google Sheets を扱うのに、**「読む」と「監視する」で別々の OAuth 接続が要る。**
結果、Google への接続は3本になり、それぞれが独立してトークンを持つ。

## テストモードの制約（未検証）

テストモードで発行されたトークンは **7日で失効する**。
n8n の Google 連携が、何もしなくても1週間後に黙って止まる。
本番公開には上記のホームページ・ポリシー要件があるため、個人検証では回避できない。

「作った人がいなくなったとき」より前に「7日後に止まる」——A-3 の題材として意図的に放置する。

## 他人の環境に納品するときの含意

- **「n8n の方が GUI で簡単」は、Google 連携の設定が終わった後の話。** 設定自体は GAS より確実に重い。
- 顧客の情シスに説明するスコープが「このファイルだけ」から「全ファイル」に変わる。
  審査の難易度が別物になる。
- 本番運用にはプライバシーポリシーページが要る。**副業として納品するなら、自分のドメインを持つのが前提条件。**
- クレデンシャルが3本あるので、どれか1本が切れると一部だけ止まる。
  「動いているように見えて一部が止まっている」の典型になる。
