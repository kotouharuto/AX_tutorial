# Slack の表示：日本語で太字が効かない／blocks があると text は画面に出ない

- **ブロック：** A-5b
- **日付：** 2026-10-17
- **一般性：** どの環境でも（日本語の文面を Slack に出すとき）
- **溶かした時間：** 未計測

## 現象

### 1. 太字にならず、アスタリスクがそのまま出る

`分類：*申請手続き*　緊急度：*低*` と書くと、画面に `*申請手続き*` と出た。

### 2. 失敗の案内が利用者に見えていなかった

ログには `missing_scope` が出ているのに、利用者の画面には分類結果しか出なかった。
「担当への通知に失敗しました」を `text` に入れていた。

## 再現手順

1. `respond(text="分類：*申請手続き*")` または blocks の mrkdwn に同じ文を入れる → 太字にならない
2. `respond(text="失敗しました", blocks=[分類結果のブロック])` → 「失敗しました」は画面に出ない

## 原因

1. mrkdwn の `*` は、**前後が全角文字（全角コロン・全角スペース）に直接くっつくと書式として認識されない。**
   5通りを見比べる観察用 Bot（`projects/a5b-slack-bot/tests/probe_format.py`）で確認：

   | 書き方 | 結果 |
   |---|---|
   | `*` が全角の「：」・全角スペースに直接くっつく | ✗ |
   | `*` の前後に半角スペース | ✓ |
   | `*` の前後にゼロ幅スペース | ✓ |
   | 半角コロンと半角スペース | ✓ |
   | 行全体を囲む | ✓ |

2. **`blocks` があると `text` は画面に表示されない**（`text` は通知用の代替文になる）

当初、1 を「ack の本文がプレーンテキスト扱いだった」と推測して blocks に変えたが、同じだった（私の誤った推測）。

## 対処

1. `*` の前後に**半角スペース**を入れる：`分類： *申請手続き* 　緊急度： *低* `
2. 利用者に見せたい文はすべて `blocks` に入れる。テストで「失敗の文が blocks に含まれる」ことを固定する

## 効かなかった対処

- プレーンテキストから blocks の mrkdwn に変える（太字は直らない）
- ゼロ幅スペースは効くが**採らなかった**：見えない文字が本文に埋まり、利用者がコピーした文に紛れ込む
  （A-6a で見えない全角スペースが設定を壊したのと同じ型）

## 他人の環境に納品するときの含意

- 日本語の文面は、**実際の Slack 画面で見るまで書式が効いたと判断しない**
- 「失敗を知らせたつもり」が画面に出ていないと、利用者は処理済みと思い込む。失敗表示は画面で確認する
