# Gemini API が HTTP 402：キーは正しいのに、前払いへの切り替えを求めて拒否される

- **ブロック：** A-5b（A-1 にも影響）
- **日付：** 2026-10-16〜17
- **一般性：** どの環境でも（Gemini API の有料利用）
- **溶かした時間：** 未計測

## 現象

分類が `Gemini が HTTP 402 を返した` で失敗した。API キーに誤りは無かった。
Google AI Studio を開くと、前払いへの変更が必要という案内が出ていた。

## 再現手順

再現は外部の課金状態に依存するため不可。

## 原因

Google AI Studio が、課金の方式を**前払い**に切り替えることを求めており、それまで API を拒否していた
（402 = Payment Required）。コード・キーの問題ではない。

## 対処

ユーザーがクレジットを購入して前払いに切り替えた → 復旧。

Tier 1 には支出の上限（250 米ドル）と、10分間で 10 米ドルを超えると `429` になる制限がある。
上限が月ごとか累計かはドキュメントに記述が無かった。

## 効かなかった対処

- API キーの確認（キーは正しかった）

## 他人の環境に納品するときの含意

- **同じキーを使う A-1 の GAS も止まっていた可能性が高い。** A-1 の「モデル名が時間で腐る（404）」と同じ型で、
  **外部サービスの課金体系の変更で、昨日まで動いていた仕組みが壊れる**
- 失敗時に HTTP ステータスを運用担当へ通知する経路があれば、402 で「支払いの問題」と切り分けられる
- 引き渡し時に、**キーの名義・支払い方法・残高の確認者**を決めておく（前払いは残高が尽きると止まる）
